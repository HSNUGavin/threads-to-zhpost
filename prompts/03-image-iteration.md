# Step 3：圖片設計迭代

## Prompt 序列

以下是針對圖片設計的多輪迭代指令：

### 3a. 簡化設計
> 圖片字太多了，應該要想好重點。例如「Claude Code 創造者自己分享的」，然後截圖他的頭像。簡潔、有吸引力，字大一點。

### 3b. 強調時效性
> 標語怎麼樣可以強調「剛分享」？

### 3c. 強調數量
> 「15 個隱藏功能」好像也該強調。

### 3d. 排版修正
> 排版看一下。（讓 Claude 自己檢查並發現問題）

### 3e. 多版本與配色
> 給我 v2 版本，標題文字大小不同呢？

### 3f. 保留版本 + 新增配色
> 原本版本可以留著嗎？要有 v1、v2。另外再給我一個 Claude 淺底色的版本。

### 3g. 定版與放大
> 留 v2 dark 和 v3 light，但字都大一點，手機閱讀方便。

## 設計心得

- 第一版往往太複雜，簡化是關鍵
- 用大小對比（小字帶出 context，大字是主訊息）比所有字一樣大更有層次
- 手機閱讀是最終標準，所有字都要夠大
- 多版本讓使用者有選擇，dark/light 適合不同平台
